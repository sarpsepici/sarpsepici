Robotics & ML engineer in Zurich, with an MSc from ETH Zurich.

### Projects

- **[Railway Danger Zone Monitoring](https://github.com/sarpsepici/anymal-danger-zone-monitoring)**: Master's thesis at ETH Zurich (Robotic Systems Lab) with SBB. The ANYmal robot watches workers on a railway site from the safe zone, using camera + LiDAR person detection, positioning and navigation in ROS.
- **[Deep-Q-Learning Ultrasound Microrobot Swarm Control](https://github.com/sarpsepici/ibm-RL-DeepQLearning)**: semester project at ETH Zurich with IBM Research. Steers a microrobot swarm with ultrasound, using image segmentation, A* path planning and deep Q-learning.
- **[Duckietown Autonomous Driving](https://github.com/sarpsepici/duckietown-autonomous-driving)**: Bachelor's thesis, team project. PID lane-following controllers for a Duckiebot in simulation.
